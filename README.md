# API de Trámites Aduanales

Proyecto integrador · Desarrollo de Software IV · UCR Sede del Pacífico

Backend REST para una agencia aduanal en Puerto Caldera: clientes, transportistas,
cargas (contenedores), trámites aduaneros y cobros.

**Equipo:** José David Jiménez Araya (C5G177) · Yerlin Oviedo Castro (C5I097)

## Puesta en marcha (versión inicial)

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (Linux/macOS: source venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
python manage.py check
```
